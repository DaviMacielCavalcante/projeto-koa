Before implementing anything new the user asks for, first discuss the best solution and trade-offs together until we are aligned — do not jump straight to coding.

**Why:** The user explicitly wants to stay aligned on approach and evaluate options before code is written.

**How to apply:** When a new request arrives, present the candidate approaches with trade-offs and wait for the user to agree on one before editing files. Applies for the whole session (and likely beyond).
